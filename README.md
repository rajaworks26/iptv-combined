# Four-country IPTV + EPG

USA, Canada, India, Pakistan. Public IPTV-org sources only. `combined.m3u` and `combined.xml` are generated by GitHub Actions. The workflow also produces `report.json`, language-filtered playlists, and an optional `favorites.m3u` driven by `favorites.json` (a JSON list of exact `tvg-id` strings).

## Setup

Upload the contents of this package to a PUBLIC GitHub repository named `iptv-combined`, preserving `.github/workflows/update.yml` and `scripts/`. Under repository Settings > Actions > General > Workflow permissions, allow Read and write permissions if needed. In Actions, run `Update four-country IPTV and EPG` on `main`. After a successful run use:

https://raw.githubusercontent.com/rajaworks26/iptv-combined/main/combined.m3u

https://raw.githubusercontent.com/rajaworks26/iptv-combined/main/combined.xml

## Important limitations

EPG coverage is incomplete and provider-dependent; generation can take a long time or fail due to blocking, changed upstream commands, or GitHub runner limits. The workflow validates before publishing, so a failed run leaves previously published files unchanged. The guide provides 3 days where providers support it. Stream URLs are not probed automatically: aggressive probing may incorrectly label region-locked or temporarily unavailable channels as broken. Category and language classification are best-effort, not authoritative. Channel logos are retained when IPTV-org provides `tvg-logo`; SD/HD is not guessed. GitHub scheduled runs may be delayed. Repository output files will not exist until the first successful workflow run.
