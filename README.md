## Sources & Attribution

This project aggregates publicly available third-party playlist and EPG sources. Those sources remain subject to their own terms, licenses, and regional availability. This repository does not host, store, or restream video content.

- iptv-org — country, category, and language playlists
- Free-TV — country playlists
- Zaman-Topu — curated global playlist
- IPTV-By-Shovo — curated global playlist
- BuddyChewChew — FAST platform playlists
- i.mjh.nz — official XMLTV schedules for Pluto TV, Samsung TV Plus, Plex, and Roku

Channel availability, legality, and geographic access vary by location. Use only content you are legally permitted to access in your region.
